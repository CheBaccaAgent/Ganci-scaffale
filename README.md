# Ganci scaffale

Modelli stampabili per il profilo metallico dello scaffale.

## Varianti

- **[V5 — perno pieno Ø25 mm, inclinato 10° verso l’alto](v5-perno-pieno-25mm/README.md)**: [STL](v5-perno-pieno-25mm/perno_pieno_25mm_10gradi_v5.stl), incastro della V4 invariato.
- **[V4 — gancio con stelo sottile](v4-stelo-sottile/README.md)**: [STL](v4-stelo-sottile/gancio_35mm_v4.stl), stelo 6,5 × 13,5 mm.

Entrambe le varianti usano una gola da 8,8 mm per un bordo ripiegato da 8 mm e restano entro una sporgenza di 35 mm.

Leggere le istruzioni specifiche: la V5 richiede supporti nell’orientamento fornito. Il carico richiesto di 0,5 kg va verificato sul pezzo stampato.
